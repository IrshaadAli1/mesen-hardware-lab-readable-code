# Changelog

## v14 — public source package

- 59 presets; five scheduling modes; up to four compatible presets simultaneously.
- The five bitplane and sprite-pixel presets are standard and selected by default. Their sprite-zero-hit caveat remains.
- Added independent four-step pulse sequences, four-step triangle bass, tap-2 repeating noise, A/Down exchange, and vertical movement coupled to A/B.
- Added GPL-3.0-or-later licensing, upstream attribution, public setup documentation and ignore rules.
- Separated runtime dependencies from test dependencies.
- Removed the two optional Unicorn-based native verification scripts from this public package pending a separate licensing review. Application behavior is unchanged; attachment messages now use public-facing wording.

Earlier development details and remaining unimplemented ideas are in docs/USAGE.md and INSPECTION.md.
